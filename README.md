# AI Smart Assistant

Build a modern, responsive web application called AI Workplace Productivity Assistant.

Create a clean, professional SaaS-style interface using black, white, and neutral shades.

Core Requirement

All generated content must come from a real AI model/API. Do NOT use hardcoded, generic, placeholder, or pre-written responses. The assistant must respond dynamically to the user's actual prompt and input.

Features

1. Dashboard

Modern professional dashboard.

Responsive sidebar navigation:

Dashboard

Smart Email Generator

AI Research Assistant

AI Chatbot

2. Smart Email Generator

User enters the purpose, recipient/context, and details.

Select tone: Formal, Friendly, or Persuasive.

Send the information to the AI and generate a unique professional email based on the user's actual input.

Output must be editable.

Include Copy and Clear buttons.

3. AI Research Assistant

User can enter a topic/question OR paste a website/article URL.

Use AI to generate:

Summary

Key Insights

Recommendations

Responses must be based on the user's actual topic, article, or accessible URL—not generic text.

If a URL cannot be accessed or analyzed, clearly explain this rather than inventing information.

Make results editable and include Copy and Clear buttons.

4. AI Chatbot

Create a real conversational AI interface.

Users can enter any workplace-related prompt.

Every response must be dynamically generated by the AI based on the user's prompt and conversation context.

Include Send, Clear Chat, Copy, and Edit functionality.

AI Integration

Connect the application to a real AI API/model so responses are genuinely AI-generated.

Use structured prompts containing the user's task, context, requirements, and desired tone.

Handle loading states, errors, empty inputs, and API failures clearly.

Do not simulate AI responses with hardcoded text.

UI/UX

Modern SaaS dashboard design.

Black-and-white professional theme.

Clean typography, cards, buttons, icons, and input fields.

Fully responsive on desktop, tablet, and mobile.

Smooth and intuitive navigation.

Privacy & Data

No backend.

No database.

No authentication.

No persistent data storage.

Do not save user prompts, emails, research, URLs, or conversations.

Keep data temporary/client-side only.

Responsible AI

Add a visible disclaimer: “AI-generated content may contain errors or incomplete information. Always review and verify AI outputs before using them for professional decisions or communication.”

Build the complete polished application with all pages, navigation, interactions, and real AI-generated responses. Do not add unnecessary features.
