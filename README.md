AI Workplace Productivity Assistant

Project Overview

AI Workplace Productivity Assistant is a modern, responsive web application designed to help professionals complete common workplace tasks using Artificial Intelligence.

The application provides AI-powered tools for generating professional emails, researching and summarising information, and interacting with an AI chatbot.

The application is designed with a clean, professional SaaS-style interface using a black-and-white colour scheme.

Features Implemented

1. Smart Email Generator

- Generate professional emails using AI.
- Supports multiple tones:
  - Formal
  - Friendly
  - Persuasive
- Generates responses based on the user's actual input.
- AI-generated output can be edited.
- Copy and clear functionality.

2. AI Research Assistant

- Research topics using AI.
- Summarise information and articles.
- Accept topics, questions, and website/article URLs.
- Generate:
  - Summaries
  - Key insights
  - Recommendations
- Editable AI-generated results.
- Copy and clear functionality.
- Provides an appropriate message when a URL cannot be accessed instead of generating fabricated information.

3. AI Chatbot

- Interactive AI chatbot interface.
- Responds dynamically to user prompts.
- Provides workplace-related assistance.
- Maintains conversation context during the active session.
- Copy, edit, send, and clear functionality.

4. Modern Dashboard

- Professional SaaS-style dashboard.
- Sidebar navigation.
- Responsive design.
- Clean black-and-white interface.
- Mobile, tablet, and desktop support.

5. Responsible AI

- Includes a Responsible AI disclaimer.
- Users are reminded to review and verify AI-generated information before using it professionally.

Technologies and Tools Used

- React – Frontend application development
- TypeScript – Type-safe development
- Vite – Development and build tool
- Tailwind CSS – Responsive styling and UI design
- AI API/AI Model – Dynamic AI-generated responses
- Lovable – Application development and UI generation
- GitHub – Source code management and version control

Data & Privacy

The application is designed without a traditional backend or database.

- No user accounts
- No authentication
- No permanent data storage
- No database
- User inputs and generated content are not intended to be permanently stored

AI-generated responses are created dynamically based on the user's prompts.

Setup Instructions

1. Clone the Repository

git clone <YOUR_GITHUB_REPOSITORY_URL>

2. Open the Project

cd ai-workplace-productivity-assistant

3. Install Dependencies

npm install

4. Configure the AI Integration

Configure the required AI API credentials according to the AI provider being used.

Do not expose private API keys directly in publicly accessible frontend code.

5. Start the Development Server

npm run dev

The application will be available through the local development URL provided by Vite.

6. Build for Production

npm run build
